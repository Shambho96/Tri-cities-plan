# Tri-cities-plan

Tri-Cities Area MPO (TCAMPO) Long-Range Transportation Plan (PLAN2050) web portal built with React, TypeScript, and Vite.

## Features
- **PLAN2050 Overview**: Regional metrics, chapter navigation, and interactive goals showcase.
- **Chapter 1 (Introduction)**: Regional context and Interactive Figure 1 Regional Map with 6 member jurisdictions.
- **Chapter 2 (Trends and Forecasts)**: Socioeconomic forecast charts (2020–2050) and county-to-county commuter flows.
- **Chapter 3 (System Today)**: Asset inventory preview and release notification signup.
- **Chapters 4 & 5 (Tomorrow & Funding)**: Future multimodal network and $1.24B fiscal constraint revenue breakdown.
- **Modern UI & Aesthetics**: Dark/light theme toggle, glassmorphic styling, and responsive design.
